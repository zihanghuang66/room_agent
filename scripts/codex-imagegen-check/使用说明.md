# room_002 单家具 Codex 内置 imagegen 测试 v0.1.0

目标：用既有 ChatGPT/Codex 登录，在学校容器测试一件真实家具的参考图生成，不提供或使用单独图像生成 API Key。不启动 TRELLIS、Blender 或完整 LiteReality 重建。

本包会消耗 Codex 会话和内置图片生成额度。只发起一个生成测试会话，提示要求最多一次 imagegen 调用、一张图片；不做自动重试，不自动切换 OpenAI/Gemini API。模型执行是否遵循单调用要求会保留事件供审查，不将提示词当作硬性服务端配额。

## 上传和运行

把 room-codex-imagegen-check-v0.1.0.tar.gz 放到 /yinxin/projects/room/scripts，执行：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-codex-imagegen-check-v0.1.0.tar.gz
bash codex-imagegen-check/run_room_002.sh
```

输入固定为 /yinxin/projects/room/data/raw/room_002/LiteReality-LiteReality_Scanner-Studio_9952-20261031-090455.tar。包独立运行，不依赖上一份 noapi 包完成。

默认使用 /opt/room/envs/app/bin/python；优先 /opt/room/tools/codex-packaged/bin/codex，然后 PATH 的 codex。沿用当前用户的 CODEX_HOME/登录；不会复制登录文件。使用此前已验证可用的 gpt-6-astra，可用 --model 指定你账号已支持的其他模型。

## 做哪些事

1. 校验并解包扫描副本到 return_output；读取原始 RoomPlan 家具及相机参数。
2. 通过包围范围投影、画面覆盖率和深度匹配选出一个家具，最多 3 个视角。保存带主视角标注的上下文、裁图和拼图。它是几何筛选，不是语义分割，遮挡或邻近家具可能仍在裁图中。
3. 调用 codex exec，附上参考拼图，要求它使用本次会话内置 imagegen；工具不可用或目标不清楚直接报告，不画占位图、不安装工具、不发图像 API 请求。
4. 保存真实输出 PNG，校验文件格式、尺寸、非空白且不等于输入；另存 1024 黑底标准化图和输入/输出对比图。
5. 收集结构化工具事件和完成状态；终端显示结果，打包回传文件。

Codex 使用已获准的容器隔离模式 danger-full-access，非交互审批 never；权限边界是学校容器及挂载目录。忽略用户 config.toml 以避免继承自定义 API provider/MCP 配置，但不读取/复制 auth.json。只在单次命令中启用 CLI 已知的 image_generation 功能，不改全局配置。exec 是非交互路径，不使用之前交互启动用的 --no-daemon。

脚本会从子进程环境去除常见图像 API Key 和 CODEX_API_KEY；不修改当前 shell、账号登录或原始扫描。提示限制只用于本次测试，不是 OS 强制文件隔离。不把内置图像生成描述为本地 GPU 推理。

## 结果如何解读

- imagegen_transport_passed_quality_pending：CLI 成功结束，拿到结构化 imagegen 调用证据及有效的新 PNG。只表示调用与保存链路通过，家具保真度必须人工检查。
- image_saved_tool_unverified：图片存在，但 CLI 事件没有暴露可识别的工具调用；不得据此宣称内置 imagegen 已验证。图片和事件仍回传用于分析。
- image_saved_turn_unverified：图片和工具事件存在，但没有可识别完成事件。
- no_generated_image / codex_failed / failed：没有生成文件、CLI 失败、超时或其他错误；终端打印关键日志，仍保存返回包。
- prepared_only_no_model_call：只选图，没有调用模型。

生成不等于还原真实结构；遮挡处可能被模型推测。先审查 inputs/primary_context.jpg、inputs/evidence.jpg、outputs/comparison.jpg，确认对象选对、家具结构保留，再决定是否接入后续 3D。

返回包路径：/yinxin/projects/room/return_output/room_codex_imagegen_时间_编号.tar.gz，以终端 RETURN_TAR 为准。原始图片是 outputs/reference_raw.png；标准化版本为 outputs/reference_1024.png。所有项目输出放在 return_output，Codex 内置工具自己的默认生成文件可能留在 CODEX_HOME 下；脚本要求复制到本次项目输出。

归档仅包含白名单内的测试报告、裁图、生成图和脱敏诊断；不含原扫描副本或 Codex 登录配置。tar/gzip 时间戳均为 0。

## 可选

只准备参考图、不消耗 Codex 额度：

```bash
bash codex-imagegen-check/run_room_002.sh --prepare-only
```

指定 RoomPlan 家具 ID（以 candidates.json 中的实际名字为准）：

```bash
bash codex-imagegen-check/run_room_002.sh --object-name Chair0
```

如果默认模型不可用，可追加 --model 你已有权限的模型名；如需指定 Codex 路径追加 --codex /完整路径/codex。默认会话最长 900 秒，超时会终止本次进程组，不自动重试。

每次运行生成新目录；重新执行默认命令会再次请求模型。不要为了看日志反复运行，应先检查 RETURN_TAR。

官方能力说明：https://learn.chatgpt.com/docs/image-generation 。官方文档描述交互 imagegen 能力；本包正是在验证你学校安装版本的非交互支持，尚不能保证该功能在当前会话中可用。
