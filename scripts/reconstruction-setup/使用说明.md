# Room 重建环境安装包

基于回传报告选择：Ubuntu 22.04、Linux x86_64、系统 Python 3.10。安装官方 `pycolmap-cuda12==4.2.1` 和 `numpy==1.26.4` 到项目内新建的独立虚拟环境；不改动系统 Python、现有 PyTorch、驱动或系统软件包。不安装 Docker、不编译 CUDA、不启动 GPU 计算。

本包是在线安装脚本，**不含依赖 wheel 文件**。需要服务器能访问 PyPI 及其文件下载地址；网络不可用时会报告失败，不自动换源或关闭证书验证。

## 执行

也可以直接上传本地 `scripts/reconstruction-setup/` 文件夹，保持服务器路径为 `/yinxin/projects/room/scripts/reconstruction-setup/`，无需解压。

将 `room-reconstruction-setup-v0.1.2.tar.gz` 上传到 `/yinxin/projects/room/scripts` 后：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-reconstruction-setup-v0.1.2.tar.gz
/usr/bin/python3 reconstruction-setup/setup.py
```

只看执行计划、不安装：

```bash
/usr/bin/python3 reconstruction-setup/setup.py --plan
```

开始安装后，将最后 `Return this archive:` 指向的报告压缩包发回。不需要回传虚拟环境或 wheelhouse。若还没生成报告就报错，发送终端错误文本。

每个步骤开始时会显示日志路径，可在另一个终端使用 `tail -f 日志路径` 查看下载进度。下载步骤最多 20 分钟，安装步骤最多 10 分钟；失败停止后续步骤并尽量打包日志。重复运行创建新环境，保留旧环境和下载文件；不要反复执行以免浪费存储，失败后优先回传报告。

## 写入位置

- `.venvs/room_setup_*/`：独立环境；未复用系统 site-packages。
- `return_output/wheelhouse/room_setup_*/`：下载的二进制包，可保留供复现使用。
- `return_output/setup_reports/room_setup_*/`：步骤日志、解析后的依赖版本、安装报告、wheel SHA256 和结果。
- `return_output/room_setup_*.tar.gz`：回传包，不包含依赖二进制文件；目录不存在时自动创建。

上述位置均位于 `/yinxin/projects/room`。该路径的跨容器持久化和用户实际配额仍需平台确认。虚拟环境依赖创建时的基础 Python，不能直接等同于可跨任意镜像迁移的环境。

本脚本借助现有 pip 的 `--python` 功能安装到无 pip 的独立 venv，避免预先要求 Ubuntu 的 ensurepip；若连 venv 模块也不可用，会停止并报告，不执行 apt/sudo。安装源固定为官方 PyPI，忽略原有 pip 配置；学校如强制内网源，应先回传失败信息再调整。

## 成功含义

`installed_import_verified` 只表示依赖检查、PyCOLMAP 导入和稀疏重建 API 检查成功。安装检查阶段屏蔽 CUDA 设备，不执行图像特征提取或重建；它不证明 GPU 运行、视频重建、稠密重建或 Mesh 生成成功，也不提供 `colmap` 命令行程序。

GPU 编号/UUID 的使用授权和视频绝对路径确认后，再提供运行小样本重建的脚本。当前不能把报告中 4 张可见 GPU 全部视为用户可用。

## 选型依据

- [COLMAP 官方 Python 安装说明](https://colmap.github.io/pycolmap/index.html)：提供 Linux CUDA 12 wheel。
- [PyCOLMAP CUDA 4.2.1 发布页](https://pypi.org/project/pycolmap-cuda12/4.2.1/)：有 CPython 3.10 / Linux x86_64 二进制包。
- [pip 官方 --python 说明](https://pip.pypa.io/en/stable/topics/python-option/)：支持管理未安装 pip 的虚拟环境。

本包仅在本地验证了脚本语法、计划输出和控制流程，尚未在学校 Linux GPU 容器完成实际依赖安装；下载后的导入日志将用于验证兼容性。
