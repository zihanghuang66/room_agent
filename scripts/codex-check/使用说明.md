# 学校容器 Codex 连通性测试 v0.1.0

不需要 GPU，不运行重建。需要 Python 3；未安装 Codex 时需要 curl。
脚本检测网络，必要时运行官方 Codex 安装器，随后使用设备码登录，并发送一次短模型请求。
安装器使用其默认用户目录，不覆盖现有 Codex 安装。认证保存在 Codex 默认凭据存储中；容器重建后是否保留取决于 HOME 是否持久化。
不要上传 ~/.codex、auth.json、设备验证码或登录日志。脚本生成的返回包只包含白名单诊断字段。

将压缩包上传到 /yinxin/projects/room/scripts 后：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-codex-check-v0.1.0.tar.gz
bash /yinxin/projects/room/scripts/codex-check/run_room.sh
```

登录时在自己的 Mac 浏览器打开终端显示的网址，输入一次性设备码。
如果提示设备码登录未启用，在 ChatGPT 安全设置启用；组织账号可能需要管理员允许。
已登录则跳过登录。请求使用现有认证：ChatGPT 登录消耗对应额度；API key 登录按 API 规则计费。
此脚本不要求输入 API key，不复制本机认证，不更改代理、证书或沙箱限制。

成功标志 RESULT: model_call_passed。仅 login status 成功或 HTTP 有响应不代表模型可用。
返回文件位于 return_output，诊断/安装器位于 return_output/artifacts。
返回包刻意不含原始日志；失败时可另外提供终端报错文字，但删除设备码和凭据。
若中断安装或登录，可能没有完整结果；可重跑。

仅做网络与版本探测（不安装、不登录、不调用模型）：

```bash
bash /yinxin/projects/room/scripts/codex-check/run_room.sh --probe-only
```

基本测试成功后，另行检查 LiteReality 当前配置的模型权限（会再消耗一次短请求）：

```bash
bash /yinxin/projects/room/scripts/codex-check/run_room.sh --model gpt-6-astra
```

测试在空临时目录中使用 read-only、ephemeral、ignore-user-config，不测试项目工具、MCP、图片理解、Blender 或 Claude。
因此通过只证明当前认证下的 Codex 文本模型请求可完成，不能证明 LiteReality 全流程可运行。
