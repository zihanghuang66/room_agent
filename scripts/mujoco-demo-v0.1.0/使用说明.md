# room_003 MuJoCo 静态查看演示

已部署主机：`huang@192.168.3.66`，Ubuntu x86_64，GTX 1070。
项目目录：`/home/huang/projects/room`。

## 启动

在 Ubuntu 桌面终端，或 SSH 登录后运行：

```bash
bash /home/huang/projects/room/scripts/mujoco-demo-v0.1.0/run_room.sh
```

窗口显示在 Ubuntu 已登录的桌面上，不会自动显示在 Mac 的 SSH 终端。
脚本前台运行，关闭窗口即可退出。可在 Ubuntu 的显示器或远程桌面中操作。

- 左键拖动：旋转。
- 右键拖动：平移。
- 滚轮：缩放。
- 左侧 Group enable 中的 Geom groups：组 1 为按对象名称识别的墙，组 2 为天花板，默认隐藏；组 0 为其余内容。
- 独立命名的门窗、装饰线条等可能仍然可见。分组只影响显示，不改变模型。

## 验证与范围

实际验证环境为 Python 3.10.20、MuJoCo 3.17.0。807 个 Blender 对象按材质拆成 839 个渲染网格，67 张基础贴图。通过真实模型编译、100 步 mj_step、有限值检查及 GPU 渲染，已打开原生交互窗口。

这不是完整物理仿真：模型无关节、无控制器，所有几何均关闭碰撞。原模型的尺寸和位置保持不变；没有依据扫描数据推断质量、摩擦或关节。不能用这个版本验证机器人碰撞、推椅子或开抽屉。

从 Desktop/to_share/room_share 中找回原始 room_003 portable.blend 后，按前一个演示的参数重新生成深灰金属腿副本，再导出，未修改源文件。不包含尚未保存并提供的 Blender 手动尺寸修改。

MuJoCo 原生 OpenGL 渲染不等同于 Cycles。保留基础颜色贴图、UV、常见 Mapping 节点缩放及 MULTIPLY 颜色调整；法线/粗糙度纹理、复杂光照、玻璃折射和镜面反射未复刻。两个椅子的空间颜色遮罩做了近似，详见转换报告。
