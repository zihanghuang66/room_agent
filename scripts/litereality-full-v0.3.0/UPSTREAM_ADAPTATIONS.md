为了现有学校容器继续运行，以下并非纯上游行为：

- 模型调用统一走已安装 Codex，MCP 桥接；旧 Claude 调用改为 Codex 适配，官方建模任务提示词保留。运行器会追加预算说明。
- 参考图通过 Codex 内置 imagegen，保存来源与文件证据、内容哈希缓存和有界重试；不把仅文本响应当作生成图片成功。
- TRELLIS/GroundingDINO 使用本地已分配 GPU，串行工作；不使用 Modal，不停止其他任务。
- Codex 事件错误检测、进程回收、缺少运行时组件立即失败。v0.3.0 仅对没有工具/未知事件/完成回答的会话启动阶段网络错误最多尝试 3 次，等待 5/10 秒，共用原时间预算；会话开始执行工具后不自动重放。
- Codex 不具备 Claude 相同的 pre-tool hook；工具预算只能通过事件计数后终止进程，不能逐工具提前拦截。只读角色的工具权限与 Claude 也不完全等价。不能据此声称两个后端行为完全一致。
- Blender 可执行文件路径、非零退出码、捕获数据链接与种子相机路径修复；导出后复查 GLB/BLEND 的几何及纹理。纹理只按完整原路径定位，不按同名文件猜测。
- 缺失参考图、无效导出、完整性评审异常明确失败，额外产物检查不替代官方视觉验收；技术检查异常标记 check_failed，避免用几何修改掩盖运行失败。
- 输入安全解压、互斥锁、同配置检查点、报告及零时间戳压缩包。依赖导入、MCP、CUDA 栅格化、Blender 渲染、Codex 命令和模型加载均提前检查，加载不等于完整推理测试。
- 本包不含 room_003 的 repair_core、专项修复任务、固定 11 帧、人工家具数、程序化替换家具逻辑。room_004 启动脚本只设置文件路径及场景标识。

v0.3.0 相对 v0.2.3：通用入口要求显式输入；删除旧场景默认值及 v0.2.2 专用续跑例外；完整导出携带纹理搬移修复；GPU 不通过时也记录数值；前置列出缺失依赖；安全范围内的会话启动网络重试；参考图产物检查将已成功生成的椅子组也计入，避免纯椅子场景因缺少普通家具元数据而误报失败。

验证边界：本地离线回归和 Mac Blender 验证不代表学校 Linux GPU、远程 Codex/imagegen、实际 room_004 全流程已通过。现场结果以本次日志及官方验收报告为准。
