# 100 帧结果的密集点云与初版 Mesh v0.1.0

只做 CPU 后处理，不下载模型权重、不重新推理、不申请 GPU。
输入固定为已核验的 room_omega_20261030T134941Z_xtkkor0g/predictions.npz，校验 SHA256 防止误用 50 帧数据。

将 room-omega-mesh-v0.1.0.tar.gz 上传到 /yinxin/projects/room/scripts，然后完整运行：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-omega-mesh-v0.1.0.tar.gz
bash /yinxin/projects/room/scripts/omega-mesh/run_room.sh
```

默认读取 /yinxin/projects/room/return_output/artifacts/room_omega_20261030T134941Z_xtkkor0g。
如果原运行目录已不存在，先将原 100 帧返回包解压到 return_output/artifacts，并通过 --source 指向包含 predictions.npz 的目录。
运行依赖 Python 3.10–3.12、可用的 pip --python 和网络下载权限；原学校环境已具备 Python 3.10 和对应 pip。
独立环境放 return_output/environments/omega-mesh-v0.1.0，不修改原 VGGT-Ω 环境。Linux 的 Open3D 若报缺少 libGL.so.1 或 libgomp.so.1，应按容器系统安装对应系统库，并返回失败日志供排查；脚本不自动执行 apt 或修改系统。
建议为初次依赖安装与输出预留至少 4 GB 磁盘空间。默认限制常用数值库为 4 个 CPU 线程。

输出全部在 return_output：
- artifacts/room_mesh_时间_随机编号/room_dense.ply：原全局置信度中位数筛选后的所有约 737 万点，无随机点数上限，未融合去重。
- room_mesh.ply：完整顶点着色三角网格。
- room_mesh_preview.glb：以 4 倍 TSDF 体素尺寸进行顶点聚类的较轻查看版，可供支持 glTF 的查看器打开。简化会损失细节，不包含纹理贴图；完整几何见 room_mesh.ply。
- mesh_preview.png：仅展示时剖切顶部，不抽样剩余三角面，不改变导出模型。
- metrics.json、日志、校验清单、result.json。
- return_output/room_mesh_时间_随机编号.tar.gz：成功或失败均打包；不重复附带模型权重和输入 NPZ。

Mesh 方法：置信度筛选、相邻前后 2 帧中至少 1 帧的 5% 相对深度一致性支持、剔除明显深度跳变，然后 Open3D TSDF 融合与表面提取。
投影采用最近像素采样，属于初版启发式筛选，不是严格可见性证明。
内部将可信深度中位数归一为 1，体素边长为该中位数的 0.5%，截断距离为 4 倍体素；最终恢复到输入坐标系。
删除少于 100 个三角面的孤立连通片；保留所有较大连通片，不只保留最大房间。
不封洞、不补造未观测表面、不平滑掩盖形变、不拆分家具。
尺度未标定为米；该版本不能当作有精确尺寸的房屋模型。GLB 查看器可能将单位理解为米，实际并未完成物理尺度标定。

启动器每次使用新输出目录，原 50/100 帧结果保持不变。打包 tar/gzip 时间戳均设为 0，避免未来时间警告。
