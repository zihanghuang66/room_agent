# Room 服务器环境检查包

适用：学校已分配的 Linux GPU 容器。需要 Bash 和 Python 3.8 或更高版本，不需要安装额外 Python 包，不需要 Docker 或 sudo。

本包只做环境检查，不安装依赖、不下载模型、不运行重建。明细报告写入 `/yinxin/projects/room/return_output/environment_reports/`，回传压缩包统一写入 `/yinxin/projects/room/return_output/`；目录不存在时自动创建。若 Python 太旧或不存在，请把终端报错发回，不必自行安装。

## 运行方法

也可以直接上传本地 `scripts/environment-check/` 文件夹，保持服务器路径为 `/yinxin/projects/room/scripts/environment-check/`，无需解压。

1. 将 `room-environment-check-v0.1.2.tar.gz` 上传到 `/yinxin/projects/room/scripts`。
2. 在已分配 GPU 的容器终端中执行：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-environment-check-v0.1.2.tar.gz
bash environment-check/run_check.sh
```

脚本逐项输出检查进度，每个外部命令最多等待 15 秒；PyTorch 探测最多等待 30 秒。工具未安装或检查失败不会中止其他检查。退出码 0 只代表报告生成成功，不代表所有依赖可用。

最后会输出 `Return this archive:`，将该行指向的 `return_output/room_env_时间_随机标识.tar.gz` 文件传回本聊天。每次执行生成独立目录，不覆盖旧报告。若没有生成压缩包，把终端错误文本发回即可。

也请从学校平台页面提供：基础镜像名称/标签，以及 `/yinxin/projects/room` 是否位于持久化挂载中。不要发送密码、令牌或私钥。

## 检查范围与限制

- 系统、架构、Python、GPU 型号/显存/驱动、CUDA 编译器、FFmpeg、COLMAP、编译工具。
- 当前 Python 环境中的指定依赖版本；不枚举其他虚拟环境。若计划使用已有虚拟环境，先激活后运行。
- PyTorch 已安装时，仅导入并探测 CUDA 可用性，不创建模型或启动训练/重建。若不希望导入它，可用 `bash environment-check/run_check.sh --skip-torch-probe`。
- 项目路径所在文件系统的空间与挂载类型，以及常见 cgroup CPU/内存限制。宿主机可见资源不等于实际容器配额；缺失限制文件需人工解释。
- 不读取 SSH 文件、完整环境变量、包管理凭据或项目数据，不调用 Docker 服务、不测试网络、不修改 NVIDIA 驱动。
- 报告含软件路径、版本和挂载信息，可先查看 `report.md` 再发送。
- `nvidia-smi` 或 `nvcc` 存在不代表算法已兼容；当前环境也未必能自行确定平台基础镜像。文件系统剩余空间不是用户配额，单次检查无法证明释放容器后数据仍保留。

源文件包括 `run_check.sh`、`inspect_environment.py` 和本文。收到报告后再确定安装脚本及版本；此包不包含尚未验证的安装命令。
