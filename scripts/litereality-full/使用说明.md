## 上传和运行

上传本包至 `/yinxin/projects/room/scripts` 后：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-litereality-full-v0.1.0.tar.gz
bash room-litereality-full-v0.1.0/run_room_002.sh --background
TERM=xterm-256color tmux attach -t room002-full
```

Ctrl-b 后按 d 可离开 tmux，任务继续运行。tmux 无法避免学校平台主动停止容器；重要结果与权重都存于持久化项目目录。不要同时启动多份任务。

没有 tmux 或需要前台查看：

```bash
cd /yinxin/projects/room/scripts
bash room-litereality-full-v0.1.0/run_room_002.sh
```

程序打印错误并保存日志，正常完成、可捕获异常、超时、Ctrl-C 都会生成 `RETURN_TAR` 指向的返回包。断电、平台强制杀容器或磁盘写满无法保证当时生成 tar；重启后收集已有结果：

```bash
cd /yinxin/projects/room/scripts
bash room-litereality-full-v0.1.0/run_room_002.sh --collect-only
```

解决错误后重新执行前台命令即可继续；上游完整阶段及有校验收据的参考图会复用。图像成功但参考图忠实度仍需人工查看，不能把生成图当作测量真值。当前 CLI 可能不记录 imagegen 调用事件：我们独立核验本次 thread 对应的全新 native generated_images 文件与输出 SHA256，并标记“间接来源证据”，不冒充完整工具追踪。

## 额度与失败判定

本次会使用 Codex 额度，也会向 Codex 发送场景证据图片。没有 OpenAI/Gemini 图像 API 调用，不自动切到 Claude/Modal。首次模型下载及 PBR 材质下载需要联网；下载固定版本并使用既有持久化缓存。耗时取决于网络、GPU 和模型响应，不能保证一次无人值守成功。

最多 24 个 imagegen 会话，跨续跑累计计数；每会话提示最多生成一次，实际工具调用次数以可用日志为准。每次参考图请求默认 900 秒，普通 Codex session 默认 3600 秒，单阶段上限 12 小时；这些是运行保护，不是美元/Token 总预算。达到上限会保留结果并报错，不静默跳过。必要时评估后用 `ROOM_MAX_IMAGE_CALLS=36 bash .../run_room_002.sh` 提高会话上限。

参考图失败不会用占位图继续；家具缺失、GLB 无效、最终验收失败或对照图缺失不会报“全部成功”。最终 `pipeline_completed_quality_review_pending` 只表示流水线和导出检查通过，还要回传目视比较真实场景。
