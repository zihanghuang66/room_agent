# 学校容器 SSH 连接拒绝排查

将 check_school_ssh.sh 上传至 /yinxin/projects/room/scripts/，在学校管理页面的 Shell 终端运行：

```bash
bash /yinxin/projects/room/scripts/check_school_ssh.sh
```

脚本检查 PID 1 程序及启动方式标记、相关进程名、主机密钥是否存在（只列文件名与权限）、sshd 配置检查、允许列出的有效配置字段、IPv4/IPv6 监听表，以及回环和容器自身地址的 22 端口 SSH banner。不会启动或重启服务，不改 SSH 配置，不打印完整启动命令、环境变量、凭据或私钥内容。

日志和 tar 均在 /yinxin/projects/room/return_output 内。发送终端末尾 RETURN_TAR 指向的文件即可；也可复制完整终端输出。

该脚本不能从容器内部证明外部 10.27.130.23:30403 的平台端口映射正确。只有结合容器实际监听和 Mac 连接结果，才能区分服务启动问题与外部映射/访问路径问题。

本地验证：r4 无 sshd 场景能报告 no hostkeys available 与 Connection refused；r4 正常服务场景能读取 IPv4/IPv6 SSH banner。两个场景均生成诊断压缩包，tar 与 gzip 时间戳固定。
