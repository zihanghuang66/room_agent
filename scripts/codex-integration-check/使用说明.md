# 沙箱与 EEVEE 修复复测 v0.1.4

本版针对 room_codex_suite_20261031T034629Z_e973194e 的问题；保留已通过的适配器 v0.1.2。最新报告里的沙箱失败是上一版预检漏传 --permission-profile 的 CLI 参数错误，没有实际运行沙箱，不能据此判断学校阻止了沙箱。

## 上传与运行

将 room-codex-integration-check-v0.1.4.tar.gz 上传到 /yinxin/projects/room/scripts/，执行：

```bash
tar -xzf /yinxin/projects/room/scripts/room-codex-integration-check-v0.1.4.tar.gz --strip-components=1 -C /yinxin/projects/room/scripts &&
bash /yinxin/projects/room/scripts/codex-integration-check/run_runtime.sh
```

顶层 scripts/，解压需要 --strip-components=1。更新脚本，不移动旧环境、数据或 fork。依赖已有 upstream-source.tar.gz、LiteReality Python 环境、Codex 登录、Blender。

## 一次完成的工作

1. 核验适配器及离线测试。
2. 对新版 Codex 使用 --permission-profile :workspace --include-managed-config，保留管理策略，不混用旧 sandbox_mode 参数。旧 CLI 只在帮助中没有 profile 功能时使用旧参数。
3. 项目目录、/tmp 分别直接运行沙箱写入、fsync、读回，无模型调用；分别记录命令、原始输出、退出码、fixture 是否启动。CLI 参数错误为 cli_usage_error，不冒充 sandbox_denied。
4. 沙箱通过后执行真实模型 shell、patch、Blender 测试；失败则跳过依赖项。文字、看图、MCP 已通过，本次专用入口不重复消耗额度。通常 3 次模型会话，必要时 /tmp 对照再增加 1 次；直接沙箱失败时 0 次。
5. 查 NVIDIA 图形库加载错误、系统库文件实际路径/软链接、ldd 依赖、宿主驱动版本、EGL vendor 配置、可能强制软件渲染的环境变量。系统路径扫描深度和数量有限，报告注明范围；没搜到不等于全系统绝对不存在。
6. CPU/CUDA/EEVEE 分别实际渲染。若 EEVEE 未用 NVIDIA，且找到与当前宿主驱动完整版本匹配的已有 NVIDIA EGL 库，则在独立子进程验证加载，并生成本轮专用 EGL vendor 配置/搜索路径，再复测 EEVEE 和 CUDA。
7. 只有 NVIDIA EEVEE 出图且 CUDA 回归通过，才生成 return_output 下的 activate_graphics.sh。候选库加载成功仅为 candidate_ready，不代表渲染修复成功。没有可确认的匹配库则停止该修复分支并报告原因，不猜测版本下载驱动。

不会修改 ~/.codex、关闭沙箱、申请更广 GPU 范围、修改系统驱动/挂载或全局库路径。图形修复仅作用于本轮渲染子进程；没有改写 LiteReality 全部渲染入口。后续流水线需要加载本轮验证通过的环境；换容器/宿主驱动后须重测。

## 输出

终端打印 ERROR BEGIN/END 和各项状态。输出均在：

- return_output/artifacts/room_codex_suite_<时间>_<编号>/
- return_output/room_codex_suite_<时间>_<编号>.tar.gz

新增 graphics_details.json、graphics_repair.json（有修复尝试时）、graphics_library_check.log（有候选库时）、候选 EGL 配置及修复前后渲染记录。只有修复成功才有 activate_graphics.sh。原始扫描和登录文件不打包；报告脱敏，tar/gzip 时间戳为 0。

runtime_checks_passed 要求沙箱、实际 shell/patch、CPU/CUDA、Codex 调用 Blender 和 NVIDIA EEVEE 通过。checks_incomplete 时，查看分项；仍不代表完整房间重建或其他模型依赖通过。保留的 run_room.sh 是完整综合测试入口，本次请运行 run_runtime.sh。

## 验证与依据

本地用单元测试及模拟 CLI/Blender 验证错误分类、跳过、库匹配、加载失败、子进程隔离和打包入口。实际本机 Codex 已接受补齐 profile 的命令参数，但本机嵌套沙箱被操作系统拒绝；不把它当成学校 Linux 沙箱通过。真实 GPU 修复必须以服务器回传结果为准。

权限配置：[OpenAI Permissions](https://learn.chatgpt.com/docs/permissions)。EGL vendor 配置：[NVIDIA libglvnd ICD 规范](https://github.com/NVIDIA/libglvnd/blob/master/src/EGL/icd_enumeration.md)。运行时挂载：[NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/docker-specialized.html#driver-capabilities)。
