## Design
- LangGraph retains original node names/checkpoints; add author_decision, author_repair, closeout nodes. Author review results that fail quality are durable receipts outside accepted publications. Human decision requests at most three small repair batches in this closeout policy. Two consecutive non-improvements, exhausted evidence without actionable defects, or total budget end normally with issues; execution failures remain resumable errors.
- Original pinned backend remains byte-identical for existing request compatibility. An explicit adapter replaces its in-process acceptance entry points during stages, using the original validators and fingerprint contract. Initial authoring still uses its original implementation; existing acceptance failures resume directly at build/review.
- Review batches list exact object IDs, require per-object coverage, use >=8/no issues/all reviewed. Start with six whole-trajectory camera frames; on missing evidence expand to at most 24 existing frames in bounded increments; no invented evidence. Persist the selected set for like-for-like reassessment. Missing evidence is never an edit instruction or a pass.
- Each repair targets at most three concrete issues, geometry first then lighting/large appearance before details. Preserve saved edits even at time/tool caps; independently rebuild/review after capped repair. Persist batch start before model call so process restart cannot create unlimited repair budgets. Preserve reviewed candidates and best-candidate pointer; do not silently replace latest sources.
- Final technical export reopen validation is separate from acceptance. Unapproved outputs remain Diagnostics. Accepted final publish still undergoes original collision, bake, validation and visual gates.
