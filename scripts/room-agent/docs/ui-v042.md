# v0.4.2 Numbered stage previews

Approved design: only previous/next arrows and a numeric counter. No view names, More menu or mode selector.

One viewer per stage/round. Latest stage remains open and historical stages collapsed. A fixed 3:2 frame contains the full source image, preserving aspect ratio. Existing side-by-side comparison sheets stay intact; individual references remain single images, with no inferred pairing or invented labels. Scene downloads stay in their own section. Clicking the image opens the existing original URL.

Store the selected image path per task and stage for the current page session. Status refreshes and newly published images preserve it; a removed selection falls back to the first image. Arrow endpoints disable. Missing images show an error in the frame while navigation remains usable. No empty or duplicate model calls are introduced.

Only the front-end, tests and delivery metadata change. Execution Python stays byte-identical to v0.4.0 / v0.4.1, preserving checkpoint fingerprints. The backend cap of 24 published images per stage is unchanged; pagination shows available previews, not all intermediate files.
