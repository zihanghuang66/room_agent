# 第三阶段 v0.3.0 实验交付状态

本版完成本地代码与交付自检，学校服务器的真实模型/GPU运行尚待验收。不是第三阶段全部完成。

## 已实现

- 已有场景界面改为“开始检查”和“修改一次并重新检查”，允许修改开关与高级修改次数上限分开；每次修改仍需点击。
- 持久单工作进程队列：排队、取消尚未执行项、重复提交保护、重启保留队列、中断任务手动继续。
- 原始扫描实验入口：扫描文件检查与真实完整重建分开；复用固定版本的旧执行器及其 pipeline.json，不重复引入内部阶段状态的写入者。
- 原始输入、执行器指纹和配置校验；任务目录隔离；阶段和日志投影；执行结束后收集预览、候选导出与返回包。
- 包含第二阶段软链接、Python3.10、日志与错误状态修复。资源锁由直接执行子进程共同持有，防止编排工作进程意外退出后错误派发下一项。

## 本地证据

- 编排与网页测试：100 passed（Python3.10.19）。包括真实 HTTP/CLI、SQLite、文件锁与工作进程强杀回归，模型/GPU部分使用测试替身。
- 原执行器相关回归：45 passed、2 skipped。跳过项不能算通过。
- 实际扫描离线验证：98,150,400 字节扫描 tar、59 对帧，完成解压与准备，结果为 prepared_only / unreviewed；没有调用模型、GPU或渲染。
- 实际浏览器核对主界面和按钮命名；网页状态与交互有自动测试覆盖，未进行服务器端人工修改闭环。
- 交付包使用归零时间戳及逐文件SHA256清单，不含扫描、权重、账号或大型运行环境。

证据保存在项目 return_output/agent_stage3_validation。完整解压包已在 Python3.10.19 下通过启动自检：100 passed，文件清单、跨进程锁和SQLite重开检查均通过。

## 未完成与限制

1. 学校服务器真实完整重建、手动修改后复评、服务重启恢复需用户验收。
2. 完整扫描内部仍由原 PipelineRunner 控制；尚未逐节点迁入 LangGraph。当前网页显示其阶段和日志，预览在尝试结束后收集，尚非全程实时图片。
3. 对话、自然语言任务理解、多用户和跨主机调度未实现。
4. 文件锁和SQLite在本机验证；学校共享盘/NFS一致性须单独确认。资源锁不约束外部训练、旧脚本或其他状态目录。
5. 强杀直接旧执行器、更深层独立进程、主机断电后的完整清理未全面验证；不能宣称任意故障均能自动恢复。
6. 不自动迁移旧版本未结束检查点，不把任务结束标成质量通过，不重新打开已经结束的任务。旧任务可在旧版本继续；新版从已有结果创建独立检查。
