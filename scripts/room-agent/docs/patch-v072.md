# v0.7.2

## Changes
- Current-source inspection is opt-in on newly confirmed session edits. It runs after immutable snapshot and environment preflight, before baseline build/render. A separate read-only Codex review must identify a unique target, cover all requirements, establish source-verifiable effective values and cite exact executable-source/data text. Uncertain claims never shortcut editing.
- A bound receipt protects reuse; timeout retries only the check. Source mutation or receipt tampering fails. No-op completion keeps the current result pointer and existing files, does not claim edit or whole-room quality approval, resolves the operation and permits another plan.
- Existing requests lack the flag and retain their graph path and node input/receipt identities. The ordinary impact-review score threshold and all checks are unchanged. Existing no-change failures are not automatically reclassified.
- Downloads filter ordinary blend from main and candidate file controls, keeping existing portable.blend and GLB. No regeneration, renaming, fallback to old revisions, or deletion.

## Validation scope
Local tests exercise the real graph, immutable snapshots, receipts, session ledger, HTTP and browser JavaScript contracts with expensive external execution mocked. School Codex source interpretation and Blender texture portability require server acceptance.
