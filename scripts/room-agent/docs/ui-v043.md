# v0.4.3 — camera comparisons and room downloads

## Root causes

The old stage collector included every image below room_preview (including object material maps), capped display images at 24, and grouped raw asset exports with room exports. The carousel changed presentation without fixing those semantics.

## Behavior

- Left: Captured. Right: Rendered. Equal frames preserve aspect ratio; arrows advance both sides. Numeric counter only.
- Index complete immutable stage snapshots and saved-review render attempts. Recognize only renderer-produced pairs/pair_NNNNN.png with the bundled 34px header, 720px image height, 8px gutter, and dimensions verified against the corresponding renders/frame_NNNNN.png. The renderer writes render left and capture right; the UI explicitly reverses those into the requested columns using SVG viewBox crops.
- Unsupported pair layouts and missing counterpart renders are not guessed. A stage without paired camera evidence has an empty state, not textures or object references. No extra render/model call is triggered.
- Show the latest available comparison group. This is evidence, not a claim of quality approval. It can precede the latest still-running build.
- Primary downloads are one latest room_preview/repair_preview directory, exact Room.glb / Room.blend / Room.portable.blend only. Object assets and earlier room revisions are folded under Other files & reports. Old capped display copies are ignored. Files are not deleted or moved.
- Seed is now labelled Initial scene (initial room assembly).

## Compatibility

Presentation code lives in ui/, outside src/room_agent/*.py execution fingerprint inputs. start_server.sh launches ui/server.py, which extends only a guarded read-only HTTP endpoint. Workers, graphs, drivers, checkpoints, pinned backends and state root are unchanged. Direct old `python -m room_agent serve` does not load this extension; use the delivered startup script.

## Validation

153 local regression checks passed, including pair orientation, 27-view indexing beyond the old cap, unsupported pairs, symlink rejection, snapshot immutability, latest room revision, preserved carousel selection, host checks and no worker launch on presentation reads.

Browser verification used 14 real comparison PNGs and their raw render PNGs from the earlier room_004 return archive. Both panes rendered correctly; next switched both to frame_00015, counter remained 2 / 14 across refreshes; object files stayed collapsed. Test task status/download placeholders were fixtures, not a new reconstruction or quality assessment.

School GPU/Codex execution was not repeated for this display-only change.
