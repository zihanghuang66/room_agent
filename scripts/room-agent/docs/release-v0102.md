# Spatial Agent v0.10.2

发布日期：2026-11-10。

本发布汇总网页工作区、对话计划与确认、证据缩略图、同会话局部编辑、独立质量复评、队列恢复和诊断功能。默认沿用持久状态目录，升级不自动重跑重建。

此次收尾将选图和评审规则抽成 `spatial-review` Skill，按实际场景布局生成目标清单并校验帧号，消除卧室专用检查项污染其他房间的问题。`spatial-edit` Skill 和既有局部编辑约束保留。详细变更见 patch-v0102.md。

## 验证

- v0.10.2 运行包：477 项本地回归通过（53.46 秒）。
- 学校真实运行：独立复评完成，24 分 22 秒；119 个实际对象、3 个全局目标、48 个匹配视角。
- 选图和评审均加载了同一 Skill；对象清单无陌生 ID，也没有遗留卧室家具要求。
- 当前保留场景未被替换；源码、初始资产、采集文件与上一轮哈希一致；无 ingest/reconstruct 或自动修复。
- 场景几何通过，视觉 5/10 未通过。62 个对象列入已评审，57 个存在证据不足。流程验收不代表质量验收。
- 本次没有发生中断，服务器对话 Resume 分支尚待真实中断验收；本地已有故障注入测试。

## 发布内容

Git tag `v0.10.2` 对应本次源码快照。Release 附件为仅含代码的学校运行包、SHA-256 校验文件和测试结果。不包含场景数据、模型权重、凭据或用户诊断包。
