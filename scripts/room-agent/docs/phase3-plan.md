# 第三阶段首个可验收版本：清晰操作、扫描入口和持久队列

**Goal:** 简化已有场景操作，接入原始扫描的现有完整执行器，并提供可重启的单工作进程队列。

**Architecture:** 沿已批准的客户端→统一服务→持久化状态→外部执行器分层。完整扫描先通过明确标注的旧执行器适配层运行，旧 pipeline.json 继续管理其内部五阶段，网页仅投影这些阶段，不让两套状态同时控制它们。第二阶段仍由 LangGraph 驱动。完整扫描逐节点迁入 LangGraph、对话界面另行验收，不伪称已完成。

**Tech Stack:** Python 3.10、现有 LangGraph/SQLite、原有 PipelineRunner、标准库 HTTP、前台服务及独立工作进程。

用户已批准分层迁移并要求继续修复、开始第三阶段。此版本为第三阶段实验交付，不宣称学校 GPU 全流程已通过。保留原入口和已有记录，不自动迁移旧代码检查点，不推送 GitHub。
