# Spatial Agent v0.10.2 — 通用场景评审 Skill

上传压缩包到 `/yinxin/projects/room/scripts`。等当前操作结束，Ctrl+C 停止旧网页服务，再运行：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-agent-stage4b-v0.10.2.tar.gz
cd room-agent-stage4b-v0.10.2
bash start_server.sh
```

沿用原 SSH 转发，打开 http://127.0.0.1:8765，刷新确认 v0.10.2。脚本前台运行，你可自行使用 tmux。

沿用 `/yinxin/projects/room/return_output/agent_state_stage2_v020`。已有任务、场景、登录和 DNS 设置保留；启动服务不会重新重建。未确认的旧草案因新增上下文可能需要重新提出，已经确认的任务和检查点继续保留。

启动会校验包、运行本地回归和 Codex 无执行工具边界探测。回归使用模拟模型/渲染，不消耗真实重建；网页确认复评后才会构建、渲染、调用真实模型。原始扫描的 ingest/reconstruct 不会因此重跑。

同一 Conversation 支持：
- 只看现有图片/源码：直接询问，不需要确认。
- 当前保留场景独立复评：给出计划，点击 Confirm & run；不会编辑或自动修复。
- 中断操作恢复：给出计划，确认后恢复同一个运行 ID 的检查点。
- 原有小范围编辑：保持原确认和验收规则。

本版不添加新扫描对话入口或新视角补图。

需要返回诊断时，使用 Summary → Files → Download Diagnosis；或：

```bash
cd /yinxin/projects/room/scripts/room-agent-stage4b-v0.10.2
bash collect_diagnostics.sh 28066a0667094a1f97f8b2e580ceb6a3
```

上方 ID 是此前会话；若测试另一会话，替换成实际 ID。压缩包保存在 return_output，终端打印完整路径。详细验收见 `验收步骤.md`。

本版不自动重跑任何任务。新复评清单来自当前布局；原始旧评审保留。按《验收步骤.md》在原对话确认一次新的只读复评即可。
