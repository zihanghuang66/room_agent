# test_01 布局诊断补收集

本脚本只读取 v0.2.1 已失败的 test_01 运行目录，收集原返回包漏掉的内部 input/scene_data 中的布局 JSON、合并记录、实拍证据和小型序列化数据。不会加载 pickle，不运行模型，不修改布局，不安装环境，不启动 tmux。

上传包到 /yinxin/projects/room/scripts，然后：

```bash
cd /yinxin/projects/room/scripts
tar -xzf room-layout-diagnostics-v0.1.0.tar.gz
bash room-layout-diagnostics-v0.1.0/run.sh
```

返回终端打印的 return_output/room_layout_diagnostics_*.tar.gz。整个原始扫描、模型权重和认证目录不会打包。每个文件最多 10 MiB、总计最多 200 MiB，缺失报告和跳过文件会在 summary.json 中记录。包内时间戳归零。
