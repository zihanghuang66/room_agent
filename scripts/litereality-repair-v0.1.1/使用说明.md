## 做哪些事

1. 复制已有 authored room 和必要证据到独立目录；原扫描只读取。保留原结果。
2. 检查 Python 依赖、现有 Codex 实际命令/MCP 执行能力。
3. Codex 基于原始照片修椅子和凳子：修形状、网布、框架和脚轮；必要时在原 wrapper 中构造可编辑替代几何，保留原神经网格和实例身份用于追溯。不会重新调用 TRELLIS。
4. 修梳妆台和书架结构、比例、重复抽屉/面板及道具摆放。
5. 修材质和局部布局，复用已下载的完整纹理。
6. 构建并冻结一个明确版本。家具缓存绑定代码、纹理及输出哈希，编辑后不能复用陈旧 GLB。
7. 验证 GLB/BLEND，打包 Blender 纹理。直接从保存的 portable BLEND 用 Cycles 渲染 11 个已知相机视角；有 CUDA 则使用，否则 CPU 回退。不依赖 EEVEE/display。
8. 执行几何检查，另起只读视觉评审会话；针对办公椅、凳子、梳妆台、书架、材质、布局/门窗逐项判断。评审文件与交付文件 SHA256 绑定，验收后不再重新导出另一版本。
9. 如未通过，最多再做两轮针对反馈的修正；仍未通过就保存候选并明确报失败。

这里的“构建”是把现有源代码导出为网格，不是重跑原始扫描重建。没有抽帧、DINO 检测、参考图生成或全场景重建。
