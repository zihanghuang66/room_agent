# room_003 物理演示录像

在 Ubuntu 主机 `huang@192.168.3.66` 的 `/home/huang/projects/room` 内录制。
输出目录为 `return_output/artifacts/room_003_mujoco_physics_v001`，最终影片为 `room003_walkthrough_physics_v002.mp4`。

## 视频内容

| 时间 | 内容 |
|---|---|
| 00–18 秒 | 房间内漫游，脚本控制相机 |
| 18–29 秒 | 同一凳子关闭重力悬停，再开启重力落地 |
| 29–41 秒 | 重置到相同位置，同样 20 N 推力持续 0.8 秒，比较家具碰撞关闭/开启；随后定格 |
| 41–54 秒 | 两个抽屉锁定时收到打开指令，再解除锁定并依次打开 |
| 54–59 秒 | 关闭两个抽屉 |
| 59–66 秒 | 显示青色简化碰撞体 |
| 66–72 秒 | 总览 |

影片是 MuJoCo 在 Ubuntu GPU 上逐帧渲染的真实物理演示，并非手工给家具做关键帧动画，也不是点击桌面界面的屏幕录制。开关由脚本改变物理状态，字幕直接读取当前开关、位移与接触数据。相机运动和章节间重置由脚本控制。

## 适用范围

- 只有原场景中的凳子（Chair2）具有自由刚体运动，其余家具固定。
- 梳妆台两个左抽屉使用模型里保存的滑动轴和范围。范围按房间里的实际缩放换算，打开目标 0.14 m。把手随抽屉一起移动。
- 凳子质量设为 4 kg，抽屉各 2 kg，摩擦系数 0.25，均为演示假设，没有实测校准。
- 桌腿和凳子使用简化盒体；其他固定家具使用保守包围盒。凳子的桌腿碰撞和落地经过数值验证。
- 抽屉有滑动关节、行程限制、驱动与锁定约束；尚未实现抽屉与柜体内部的精细接触。
- 家具碰撞关闭时仍保留地板碰撞，使对照只改变家具阻挡。
- 相机不受碰撞限制。颜色、金属和透明效果不等同于 Blender。

## 重录

```bash
ssh huang@192.168.3.66
bash /home/huang/projects/room/scripts/mujoco-demo-v0.2.0/run_record.sh
/home/huang/projects/room/.venv-mujoco/bin/python \
 /home/huang/projects/room/scripts/mujoco-demo-v0.2.0/verify_video.py \
 /home/huang/projects/room/return_output/artifacts/room_003_mujoco_physics_v001
```

依赖除之前的 MuJoCo 和 Pillow 外，增加 `imageio-ffmpeg==0.8.1`，在同一独立虚拟环境内安装。脚本前台运行，不需要学校服务器。

`physics_checks.json` 是独立数值验证；`recording_trace.json` 保存影片中的实际状态；`video_validation.json` 验证所有视频帧可解码，并核对录制中的物理对照。
